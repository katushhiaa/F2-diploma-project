## Матриця нефункціональних вимог (NFRs Matrix)
 
| Категорія | Вимога | Цільове значення |
|---|---|---|
| Продуктивність | Пропускна здатність REST API | ≥ 500 RPS на екземпляр; до 2 000 RPS на 4 репліках |
| Продуктивність | Латентність читальних ендпоінтів | p95 ≤ 200 мс, p99 ≤ 500 мс |
| Продуктивність | Латентність записувальних ендпоінтів | p95 ≤ 300 мс |
| Продуктивність | Прийом OCR-запиту (202 Accepted) | ≤ 150 мс (p95) |
| Продуктивність | Оброблення OCR-завдання | ≤ 15 с (p95) |
| Продуктивність | Доставка події WebSocket | ≤ 500 мс (p95), до 1 000 з'єднань на екземпляр |
| Кешування | Redis, метадані видань | hit ratio ≥ 80%, TTL 24 год |
| Пагінація | Курсорна | максимум 50 записів на сторінку |
| Безпека | Транспорт і зберігання | TLS 1.3, AES-256 для томів, секрети поза репозиторієм |
| Безпека | Автентифікація | JWT: access 15 хв, refresh 7 діб з ротацією; bcrypt cost ≥ 12 |
| Безпека | Rate limiting | Гість 60/хв (IP); Читач 300/хв; auth-ендпоінти 10/хв |
| Безпека | Стандарти | OWASP Top 10, ASVS рівень 2; файли ≤ 5 МБ (JPEG, PNG, WebP) |
| Безпека | Авторизація | Перевірка членства в кімнаті на кожен запит і WS-підписку; 403 (для приватних цитат 404) |
| Комплаєнс | GDPR | Видалення акаунта ≤ 30 діб; явна згода на контакт і внесок у статистику; privacy by design |
| Приватність | Агрегація цитат | k ≥ 5 унікальних авторів; лише за згодою; кластер без посилань на користувача |
| Спойлери | Серверна фільтрація | 100% відповідей через єдиний шар; тести покривають усі гілки правил |
| Надійність | Доступність | ≥ 99,5% на місяць; RTO ≤ 1 год; RPO ≤ 24 год |
| Надійність | Відмовостійкість | OCR retry до 3 (експоненційна затримка), dead-letter черга, ідемпотентність; circuit breaker (5 збоїв, тайм-аут 3 с) |
| Інфраструктура | Контейнеризація | Docker Compose, health/readiness-перевірки |
| Інфраструктура | Резервне копіювання | Щоденно, зберігання 14 діб, щомісячна перевірка відновлення |
| Спостережуваність | Моніторинг | Prometheus, Grafana, JSON-логи (pino) з correlation ID; алерти: p95 > 500 мс або 5xx > 1% |
| Якість | Тестування та UI | Покриття критичної логіки ≥ 80%; WCAG 2.2 AA |
